# 동행

### 팀 동행자 | 고령자·초보 운전자를 위한 안심 운전 준비 도우미

**동행**은 운전자가 출발 전에 걱정되는 상황을 살펴보고,
차량 조작을 미리 배우며, 어려웠던 내용을 다시 복습할 수 있도록 돕는
Pleos Connect 기반 인카 앱입니다.

## 프로젝트 소개

고령자와 초보 운전자는 복잡한 도로뿐 아니라 와이퍼, 공조, 김서림 제거처럼
차량을 조작하는 상황에서도 부담을 느낄 수 있습니다.

동행은 사용자의 유형에 맞는 화면과 안내를 제공하고,
**출발 전 점검 → 경로 준비 → 차량 조작 학습 → 복습**을
하나의 흐름으로 연결합니다.

## 주요 기능

- **사용자 맞춤 화면**  
  고령자·초보자·직접 설정 유형을 선택하고 글자 크기, 대비,
  화면 모드와 안내 상세도를 조절합니다.

- **걱정 상황 선택**  
  비 오는 날 와이퍼, 앞유리 김서림, 차로 변경, 후진 주차 등
  미리 살펴보고 싶은 상황을 선택합니다.

- **출발 전 점검**  
  안전벨트, 좌석과 거울, 문과 차량 주변 등 출발 전 확인할 항목을
  사용자가 직접 점검합니다.

- **경로 비교 시연**  
  소요 시간과 방향 전환 횟수를 비교하는 화면을 제공합니다.
  현재 시연 화면의 경로와 수치는 **가상 데이터**입니다.

- **차량 조작 안내와 복습**  
  와이퍼·공조·김서림 제거 등의 설명을 확인하고,
  다시 보고 싶은 내용을 복습할 수 있도록 구성합니다.

- **설정 및 복습 기록 관리**  
  사용자 설정과 복습 기록을 저장·복원하며,
  데이터 손상과 저장 실패 상황에 대한 보호 기능을 보강하고 있습니다.

## 현재 개발 상태

현재는 공모전 영상 제작을 위한 **시연용 앱**을 개발하고 있습니다.

- 시연용 경로 비교에는 실제 경로가 아닌 가상 데이터를 사용합니다.
- Vehicle SDK의 안전한 비동기 요청 종료 방법을 확인하기 위해
  실제 차량 SDK 조회는 현재 임시 차단되어 있습니다.
- 공조·김서림의 실제 신호 기반 완료 판정과 실차 검증은
  아직 진행되지 않았습니다.
- 실제 차량·내비게이션 데이터는 SDK 제공 범위와 안전 조건을
  확인한 뒤 단계적으로 연동할 계획입니다.

## 기술 스택

- **언어:** Kotlin
- **UI:** Jetpack Compose
- **개발 도구:** Android Studio
- **차량 플랫폼:** Pleos Connect
- **SDK:** Pleos Connect Vehicle SDK, NaviHelper SDK
- **테스트 환경:** Pleos Connect 에뮬레이터 및 Virtual Console


## 유의사항

동행은 운전 준비와 학습을 돕는 보조 앱입니다.
차량의 공식 안내와 매뉴얼을 우선 확인하고,
최종 운전 판단은 운전자가 직접 해야 합니다.
