# 출시 빌드 확인 사항

현재 저장소 설정의 `versionCode`는 1, `versionName`은 1.0이다. 출시 전에는 배포 이력과 충돌하지 않도록 배포 담당자가 버전 코드 증가 및 버전 이름을 결정한다.

`release`는 최적화 설정이 있으나 출시 서명·설치·실행·난독화 회귀는 아직 검증하지 않았다. 서명 키와 비밀번호는 저장소에 넣지 않는다. 조직의 안전한 비밀 저장소와 Gradle 서명 설정을 사용하고, 검증된 키와 배포 권한은 담당자가 관리한다.

시연용 경로 후보는 `src/demo`에만 정의한다. release에서 실제 후보를 확인하지 못하면 비교 불가로 남긴다. 진단 화면과 기록기는 빌드별 소스로 분리했다. 병합 manifest에 휴대폰 미리보기 Activity가 없고, release DEX에서 검사한 시연 경로·진단 문자열 표식이 없음을 확인했다. 이는 전체 바이너리 또는 실행 중 격리의 완전한 검증이 아니므로 추가 확인이 필요하다.

Windows에서 demo와 release를 빌드한 뒤 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-release-isolation.ps1`로 알려진 네 표식을 재검사할 수 있다. 표식이 demo에 없거나 release에 있으면 실패한다. 서명·실행·다른 가상 데이터의 부재를 검증하지는 않는다.

차량 UX 정책, Pleos 마켓 등록 요건, 주행 제한 및 실차 권한은 **확인 필요**다. 실제 주행 시험·접근성·개인정보·오류 복구 검증 전 출시 준비 완료로 표시하지 않는다.
