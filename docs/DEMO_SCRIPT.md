# 공모전 시연 대본 — 빌드 및 기기 확인 필요

## 준비와 실행

- demo는 별도 앱 ID `com.example.hyundiaboysranger.demo`를 사용한다. 화면 상단에 **시연용**이 표시되며 시연 흐름에는 가상 예시라는 안내가 표시된다. 차량 SDK 기본 차단과 주차 FeatureGate는 유지된다.
- Android Studio 터미널에서 JDK와 필요한 Android SDK가 설정된 상태로 `.\gradlew.bat --no-daemon testDebugUnitTest assembleDemo`를 실행한다. 기본 demo APK 출력은 `app/build/outputs/apk/demo/` 아래다. 빌드 성공을 확인한 뒤 Pleos 에뮬레이터에 demo APK를 설치하고 demo 앱을 실행한다. 기존 `run-app.cmd`는 debug용이므로 demo 실행에 사용하지 않는다.
- P단, 속도 0, 화면 사용 허용이 실제 주차 게이트에서 확인되어야 시연 화면이 열린다. 확인되지 않거나 도중에 조건이 사라지면 제한 화면이 나타난다. 신호를 가상으로 만들어 게이트를 우회하지 않는다. 제한 화면이 계속되면 촬영을 중단하고 환경을 확인한다.
- 기존 앱의 설정과 복습 기록을 삭제하거나 초기화하지 않는다. 시연 흐름의 선택과 복습은 화면 상태에만 보관되며 앱 종료나 주차 잠금 등으로 사라질 수 있다. 기존 앱은 첫 화면의 '기존 앱 열기'로 접근한다.

## 촬영 순서

1. 주차 제한 조건이 충족된 상태에서 demo를 열고 상단 **시연용** 표시와 가상 예시 안내를 보여준다. 고령자 또는 초보자를 선택한다. 이 선택은 시연 화면용이며 기존 사용자 설정을 바꾸지 않는다.
2. '비 오는 날 와이퍼' 또는 '유리 김서림'을 선택한다. 출발 전 점검 항목을 직접 선택하고 '시연용 경로 비교'를 누른다. 체크는 사용자의 수동 선택이며 센서 판정이 아니다.
3. 가상 경로 A와 B를 비교하고 하나를 선택한다. 시간과 회전 수는 미리 만든 예시이고 실제 경로 계산이나 안전도 평가가 아니다.
4. 선택한 걱정 상황의 조작 설명을 읽는다. 실제 와이퍼·공조 작동이나 차량 신호를 감지했다고 말하지 않는다. '어려운 항목을 시연 복습에 추가'를 누른다.
5. '시연 복습 보기'를 눌러 복습으로 이동한다. 추가된 항목을 확인하고 '설명 다시 확인' 또는 '이전'으로 돌아갈 수 있다. '시연 종료'는 임시 선택과 복습을 지우고 시작 화면으로 돌아간다. 작은 화면에서는 아래로 스크롤한다.

## 확인 결과와 남은 문제 (2026-11-09)

- 소스 검토: 시연 화면은 demo 소스에만 있으며 실제 주차 게이트 뒤에서 열린다. `VehicleSdkAccess.enabled`는 `false`다. 기존 설정·복습 저장소에 시연 선택을 기록하지 않는다.
- 이번 실행: `git diff --check` 통과. Gradle은 JDK 지정 후 `C:\.gradle\wrapper\dists\...` 잠금 파일의 상위 디렉터리를 만들지 못해 시작 전에 중단됐다. 단위 테스트, Kotlin 컴파일, demo APK 빌드는 **미검증**이다. 초기 시도는 JAVA_HOME/PATH에 Java가 없어 중단됐다.
- 이번 변경본은 Pleos에 설치하거나 실행하지 않았다. 촬영 순서, 화면 크기·스크롤·버튼, 주차 조건 및 앱 상태 복원은 기기에서 미검증이다. 빌드 및 기기 확인 후에만 촬영 가능 여부를 판단한다. 실제 차량 기능과 안전성은 검증하지 않았다.
- 시연 복습은 영구 복습 기능이 아니다. 현재 경로와 조작은 고정 설명 예시이며 실제 내비게이션·차량 조작과 연결되지 않는다. 디자인과 접근성의 전체 검증은 남아 있다.

## 시연 화면 이동 수정 검증

- 조작 설명에 '시연 복습 보기', 복습 화면에 '시연 종료'와 '이전'을 제공한다. 종료는 시연 화면의 임시 상태만 초기화한다. 단계마다 스크롤 위치를 초기화하고 세로 스크롤 안내를 표시한다.
- 이번 변경 후 에이전트 빌드는 Gradle 배포본 잠금 파일 접근 거부로 태스크 시작 전 중단됐다. 테스트·컴파일·demo 빌드와 큰 글자·좁은 화면의 실제 스크롤 동작은 미검증이다. Android Studio 터미널에서 별도 출력으로 `.\gradlew.bat --no-daemon -I build/demo-navigation-check-init.gradle testDebugUnitTest assembleDemo`를 실행해 확인한다. 기존 APK는 덮어쓰지 않았다.
