# 3분 시연 초안 — 실행 전 재검증 필요

이 대본은 준비안이다. 현재 변경본의 Pleos 시연과 실제 차량 동작은 검증하지 않았다. demo 빌드는 별도 앱이며 화면에 **시연용** 표시가 나타나야 한다. 실제 SDK 값과 가상 경로를 구분한다.

| 시간 | 화면과 행동 | 확인·대안 |
|---|---|---|
| 0:00–0:30 | 앱 실행, 주차 상태와 데이터 출처 확인 | 주차가 확인되지 않으면 잠금 화면을 보여주고 우회하지 않는다. |
| 0:30–1:00 | 출발 전 수동 점검, 복습·경로 화면 진입 | 점검은 사용자가 직접 선택하며 자동 센서 확인이 아니다. |
| 1:00–1:30 | demo 경로 비교 예시 | 가상 후보와 임시 점수임을 밝힌다. 실제 후보·도로 폭·안전 점수로 주장하지 않는다. |
| 1:30–2:15 | 와이퍼 연습 | 사전에 SDK OFF/ON/OFF 수신이 검증된 경우만 시연한다. 확인 불가면 미완료 상태를 보여준다. 공조·김서림은 잠겨 있다. |
| 2:15–2:40 | 경고등 사전 학습 | 일반 참고 자료이며 실경고 감지나 차종별 매뉴얼을 대체하지 않는다. |
| 2:40–3:00 | 동의된 기존 복습 확인 및 한계 설명 | 기존 사용자 데이터는 삭제하거나 초기화하지 않는다. 실제 서비스 미검증 항목을 설명한다. |

사전 확인: 빌드 버전과 시연용 배지, 주차·권한, 실제 SDK 응답, 기기 설정과 기존 복습 기록 보존, 큰 글씨 화면을 확인한다. 기본 내비 연결 실패·지도 미표시·차량 신호 미수신 시 확인 불가를 표시하고 차량의 기본 안내를 이용한다. 차량 상태를 시험 목적으로 바꿨다면 시작 값을 기록하고 가능한 경우 복원한다.
